# Тестирование идемпотентности заказов

В этом разделе описаны тесты для проверки идемпотентности API создания заказов с использованием заголовка `X-Idempotency-Key`.

## Коллекция тестов

Файл `idempotency_test_collection.json` содержит Postman-коллекцию для тестирования идемпотентности создания заказов. Коллекция включает следующие сценарии:

### 1. Подготовка окружения

- **Регистрация пользователя**: создаёт тестового пользователя со случайными учетными данными
- **Авторизация пользователя**: авторизует пользователя и получает токен
- **Пополнение баланса**: пополняет баланс пользователя на 1000.00 единиц

### 2. Тесты идемпотентности

- **Создание заказа (первый запрос)**: создаёт заказ с уникальным идентификатором запроса (`X-Idempotency-Key`)
- **Создание заказа (повторный запрос)**: повторяет тот же запрос с тем же идентификатором - должен вернуть уже созданный ранее заказ
- **Создание заказа (новый идемпотентный ключ)**: отправляет запрос с новым идентификатором - должен создать новый заказ
- **Запрос без идентификатора (ошибка)**: проверяет, что система отклоняет запросы без заголовка `X-Idempotency-Key`

### 3. Проверка созданных заказов

- **Получить заказ по ID (первый заказ)**: проверяет, что первый заказ успешно создан и доступен
- **Получить заказ по ID (второй заказ)**: проверяет, что второй заказ успешно создан и доступен
- **Список заказов пользователя**: проверяет, что оба заказа присутствуют в списке заказов пользователя

## Переменные окружения

Для запуска тестов необходимо настроить следующие переменные окружения:

- `baseUrlOrder`: URL сервиса заказов (по умолчанию http://localhost:8080)
- `baseUrlBilling`: URL сервиса биллинга (по умолчанию http://localhost:8081)

## Запуск тестов

1. Импортируйте коллекцию `idempotency_test_collection.json` в Postman
2. Создайте или выберите окружение с необходимыми переменными
3. Запустите коллекцию через кнопку "Run collection"

## Ожидаемые результаты

- При первом запросе создания заказа должен вернуться код 201 (Created)
- При повторном запросе с тем же `X-Idempotency-Key` должен вернуться код 200 (OK) и данные ранее созданного заказа
- При запросе с новым `X-Idempotency-Key` должен создаваться новый заказ (код 201)
- При запросе без `X-Idempotency-Key` должна возвращаться ошибка 400 (Bad Request)
